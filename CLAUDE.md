# Instagram Cleanup

Chrome MV3 extension (Svelte 5, Vite, Tailwind v4) to swipe through followed accounts and decide who stays. Spec: `docs/superpowers/specs/2026-11-05-ig-cleanup-design.md`. Plan: `docs/superpowers/plans/2026-11-05-ig-cleanup-mvp.md`. Scripts: `npm run dev` (watch build), `npm run build` (to `dist/`, load unpacked), `npm run check` (svelte-check), `npm run lint` (biome), `npm test` (vitest). Log with `src/shared/log.ts` (`[igc]` prefix).
